Instant Serve – Real-time Food Ordering & Delivery Platform

A full-featured platform for real-time food ordering and delivery management, built with ASP.NET Core, RESTful APIs, SignalR, and a responsive Admin Dashboard.

Features

Real-time Order Updates: Implemented with SignalR for live order status notifications.

RESTful APIs: Full CRUD operations for managing orders, users, and deliveries.

Admin Dashboard: Monitor pending orders, update statuses, and manage the delivery process.

Responsive Frontend: Built with HTML, CSS, and JavaScript for smooth user experience.

Order Management: Handles multiple orders concurrently with real-time tracking.

Tech Stack

Backend: ASP.NET Core MVC, C#

Real-time Communication: SignalR

Frontend: HTML, CSS, JavaScript

Database: SQL Server / Entity Framework Core

Version Control: Git / GitHub
